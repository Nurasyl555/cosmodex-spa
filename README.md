# 🚀 CosmoDex — Exoplanet & Space Mission Archive (React SPA)

**CosmoDex** — это интерактивное одностраничное веб-приложение (Single Page Application), разработанное на **React** и **Vite**. Приложение представляет собой исследовательскую базу данных экзопланет и космических миссий (Kepler, James Webb, TESS, Hubble, Spitzer).

---

## 🌟 Основные возможности проекта

1. **Simulated Asynchronous API (105+ записей):**
   * Реализация асинхронного API с использованием `Promise`, имитации задержки сети (`setTimeout`) и персистентного хранилища `localStorage`.
   * В начальной базе **105 детально описанных экзопланет** (превышает требование в 100 записей).
2. **Поиск, Фильтрация, Сортировка и Пагинация:**
   * **Поиск:** Полнотекстовый поиск по названию планеты, родительской звезде и описанию.
   * **Фильтрация:** По классу планеты (*Terrestrial, Super-Earth, Gas Giant, Neptune-like*) и обитаемости (*Зона жизни*).
   * **Сортировка:** По названию (алфавит), расстоянию от Земли, году открытия и массе (по возрастанию / убыванию).
   * **Пагинация:** Разбиение на страницы по 12 карточек с умным переключением номеров.
3. **List View & Detail View:**
   * **List View:** Сетка карточек с бейджами, характеристиками и цветовой дифференциацией.
   * **Detail View:** Полноценный научный паспорт объекта (температура в Кельвинах и Цельсиях, масса, год открытия, спектральный класс звезды) с поддержкой закрытия по клавише `Escape` и клику вне окна.
4. **Controlled Form (Управляемая форма):**
   * Модальное окно для добавления новой планеты с валидацией полей, выводом ошибок и сохранением в базу данных `localStorage`.
5. **Обработка 4 состояний интерфейса:**
   * **Loading:** Анимированный спиннер при запросах к API.
   * **Error:** Экран сбоя соединения с возможностью повторить запрос (`Retry`).
   * **Empty:** Сообщение об отсутствии результатов с кнопкой быстрого сброса фильтров.
   * **Success:** Отрисовка списка данных.
6. **Надежная работа с эффектами и состоянием:**
   * Защита от **Race Conditions** и **Stale Closures** с помощью функции очистки (`cleanup function`) и флага отмены `isCancelled`.
   * Стабильные ключи `key={planet.id}` (без использования индексов массивов).
   * Иммутабельные обновления состояния (`setFormData(prev => ({ ...prev, [name]: value }))`).
   * Отсутствие прямых манипуляций с DOM.

## 🏗 Архитектура компонентов

Проект разделен на 7 независимых переиспользуемых компонентов:
* `src/components/Navbar.jsx` — Верхняя шапка, статистика базы, сброс к дефолту и кнопка вызова формы.
* `src/components/FilterBar.jsx` — Панель фильтров, поиска и сортировки.
* `src/components/PlanetCard.jsx` — Карточка отдельной экзопланеты.
* `src/components/Pagination.jsx` — Навигация по страницам.
* `src/components/PlanetDetailModal.jsx` — Детальный просмотр с `cleanup` слушателя событий.
* `src/components/AddPlanetModal.jsx` — Управляемая форма с валидацией.
* `src/components/StatusView.jsx` — Универсальный экран состояний (Loading / Error / Empty).

## 🛠 Запуск проекта локально

1. Склонируйте репозиторий:
   ```bash
   git clone <URL_РЕПОЗИТОРИЯ>
   cd midterm-cosmodex
   ```
2. Установите зависимости:
   ```bash
   npm install
   ```
3. Запустите локальный сервер разработки:
   ```bash
   npm run dev
   ```
4. Соберите проект для продакшена:
   ```bash
   npm run build
   ```
